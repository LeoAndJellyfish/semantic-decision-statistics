# 新论文的研究框架与复现说明

论文：**语义决策模型在统计分析中的应用：方法论框架与研究议程**。构造研究日期：2026年10月5日；论文第二版：2026年10月6日；语言修订：2026年10月25日。

## 研究问题与贡献

核心问题：研究者依据自然语言标准获取类别判断、成对关系及等级概率后，监督信息、分组结构和测量变量应如何构造？哪些收益可以在固定目标、统计方法和预算下验证？

论文采用用户提出的八节架构，以分类和聚类为主线。框架联系研究标准、判断获取、概率读取和整体结构求解，按标签、关系、等级组织统计用途。分类讨论直接编码、弱监督融合、学生模型训练及人工复核；聚类展开关系目标、图覆盖、冲突和概率加权。序数测量及记录链接作为扩展应用，SMS 总体估计移至附录B，作为下游案例。

第二版另在第4.4节纳入 Tev1 标题提取错误识别的真实分类案例，重分析见 `../title_case/README.md`。真实语料上的聚类来源比较列为第7.4节的后续研究设计。本文使用既有相关聚类目标、概率损失和模型辅助估计工具；理论误差界来自线性损失的直接推导。

## 构造研究

- 九条原型完全交叉三种产品与三种机制。记录文本及预设机制见 `records.csv`。
- 构造表示为 `[2×产品单位向量，机制单位向量]`。固定三组的平方误差全局最小解按产品划分，SSE=6，机制参考 ARI=-1/3。
- 全部36对构成候选图。每次随机排列，前12、24、36对为嵌套查询集合。每种条件重复1,000次，NumPy PCG64 种子20261005。
- 四种条件为完整正确判断、异质可靠度、同信号的过度集中概率、关系标准偏移。全部判断由模拟生成；无外部模型请求。
- 异质可靠度取0.95或0.80，同组先验0.25，返回概率依据论文中的贝叶斯公式计算。先验与可靠度由构造给定。模拟中的校准对象为均匀抽取记录对时的边际关系。
- 二元与概率方法在相同查询图上枚举全部21,147个划分。主并列规则依次使用产品关系损失、簇数、原始枚举顺序，参考机制标签未参与并列选择。
- 在主要结果检查后补充并列规则敏感性分析，替代规则依次使用最少簇数和原始枚举顺序。此项补充使用相同随机数据，不属于事先注册设计。
- 严格满足全部二元约束的可行性与允许违反约束的最小不一致划分分别报告。

复现命令：

```powershell
python scripts/semantic_clustering_study.py
```

本轮环境为 Python 3.12.14、NumPy 2.3.5；实际运行版本同时记录在 `results.json`。程序仅依赖 NumPy 及标准库，约十秒完成。输出文件为 `records.csv`、`replications.csv`、`summary.csv` 和 `results.json`。

## 主要结果与解释

24次查询的异质条件下，二元与概率方法平均 ARI 分别为0.5067和0.5733，配对差异0.0666，蒙特卡洛标准误0.0058。36次查询的严格硬约束可行比例为1.3%。过度集中概率保留相同判断信号，其 Brier 分数较高，平均 ARI 增益较小。标准偏移条件按产品关系生成判断，三个预算的机制 ARI 均为负值。

稀疏查询支持多个最优解。完整正确条件中，24次查询有60.6%的重复出现并列最优；主规则与替代规则的平均 ARI 分别为0.8646和0.9896。正文报告这一敏感性，解释查询图上的最优性与完整划分识别之间的关系。

异质可靠度的完整图中，二元与概率损失存在并列最优的比例分别为54.4%和31.2%。最少簇数优先规则下，二元与概率平均 ARI 分别为0.8469和0.7771，方法排序与主规则相反。摘要及讨论据此明确解选择和评价指标对比较结论的作用。

未舍入指标、每项蒙特卡洛标准误、完全恢复比例、成对误差、三元组冲突及替代规则结果均保存在结果文件。构造结果表对应 `summary.csv` 的十二行；主要数值条件保持固定。
