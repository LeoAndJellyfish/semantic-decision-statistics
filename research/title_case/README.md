# 真实分类案例：论文标题提取错误识别

研究日期：2026年10月6日。本目录服务于论文第二版第4.4节。案例来自信息检索课程项目二；原实验于2026年10月3日至6日完成，本轮沿用冻结预测，新增指标复算、条件性配对重抽样与错误代价分析。

## 来源与数据

原始材料：[paper-title-error-classification](https://github.com/LeoAndJellyfish/paper-title-error-classification/tree/1b0ce28d265454680b5b383bbb7ff0929dca688b)，固定提交为 `1b0ce28d265454680b5b383bbb7ff0929dca688b`。材料与模型卡的原始字节校验值保存在 `provenance.json`。

课程训练文本共236,158行。空行、类内重复、测试重叠和训练标签冲突清理后保留212,385条，按种子42分层划分为训练169,908条、验证42,477条。参考标签来自课程文件。测试集1,000条包含568条正确提取、432条错误提取；24条空标题统一采用错误提取规则，其余976条由模型判断。

标题身份使用 NFKC、casefold、空白合并与首尾清理。本轮独立读取上游处理数据 ZIP，核对内部文件 SHA-256，确认三个分区的标题交集为零。测试集的非空标题归一化后有963组：正确提取568组，错误提取395组，包含13次重复出现。

模型输入为机器提取标题。原题名、文献 ID 和参考标签用于追溯与评价。文本形式上的标题完整性和实际提取与原文的对应关系，在说明性错误样本中分别核对。

公开复算文件 `predictions.csv` 包含参考标签、空标题标记、标题组编号和六组模型输出。`title_identity` 列按归一化标题首次出现的顺序编号，用于保持原有的配对重抽样分组。标题原文与文献 ID 可在上游固定提交中核查。

## 比较设计

保留六项已完成的预测：词频多项式 NB、Word2Vec＋SVM、冻结 BERT＋SVM、Tev1／Ollama Q4_K_M 零样本、Tev1／Transformers NF4 零样本与 Tev1／NF4＋QLoRA。上游报告以五种主方法展示，NF4 零样本另作为微调的配对对照。

NF4 对照与微调共用基础模型版本 `0b7becf017daa0e5eb222f8ce7483c8c8259c52f`、量化、模板、选项顺序及逐条评分程序，在同一模型实例中关闭或启用任务适配器。第10,620步按验证集宏平均 F1 85.91% 入选，检查点选择先于测试评价。QLoRA 训练使用全部169,908条任务标签。Ollama 的 Q4_K_M 量化、输入构造和接口评分与 NF4 方案同时变化，其完整部署结果单独报告。

## 本轮结果

| 项目 | NF4 零样本 | NF4＋QLoRA |
| --- | ---: | ---: |
| 准确率 | 75.10% | 89.80% |
| 宏平均 F1 | 71.13% | 89.69% |
| 错误类精确率 | 96.45% | 85.41% |
| 错误类召回率 | 43.98% | 92.13% |
| 漏检 | 242 | 34 |
| 误报 | 7 | 68 |
| 非空记录 Brier | 0.1685 | 0.0993 |
| 非空记录对数损失 | 0.5111 | 0.3988 |
| 十等宽区间校准误差 | 0.1704 | 0.1301 |

微调纠正210条零样本误判，并新增63条误判。宏平均 F1 差异为18.57个百分点，条件性配对自助区间为15.46至21.78个百分点。相较冻结 BERT＋SVM，宏平均 F1 差异为8.34个百分点，区间为6.08至10.61；误报少67条、漏检少17条。

若漏检与误报的单位代价分别为 `c_FN`、`c_FP`，固定测试预测下的微调损失变化为 `-208*c_FN + 61*c_FP`。代价比 `c_FN/c_FP > 61/208 ≈ 0.2933` 时，微调方案的测试误判损失较低。标签、训练与核验投入另列为方案总成本。

## 重分析与不确定性

```powershell
python scripts/title_case_analysis.py
```

程序依赖 NumPy 与 Python 标准库，读取本目录的 `predictions.csv` 和 `provenance.json`，复算12行完整／非空分类指标、三项概率指标及10,000次重抽样结果，保存 `summary.csv` 和 `results.json`。本轮 Python 3.12.14、NumPy 2.3.5，种子20261006；运行约三秒。

重抽样单元为963个归一化非空标题组，按参考类别分别抽取相同数量的组，组内记录随组共同重复，六种方法使用相同抽样权重。每次加入24条固定规则记录，计算完整评价口径下的指标差异，采用2.5%与97.5%百分位数。区间以固定训练结果和测试来源构成为条件，训练波动通过后续重复训练评价。该补充分析在查看既有结果后制定。
